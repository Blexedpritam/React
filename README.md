# React Learning Projects

A focused React learning repository designed to explore the fundamentals of modern React development through two progressively advanced mini-projects.

This repository contains:

- `hello-world` — a beginner-friendly introduction to React and Vite
- `core-concepts` — a deeper look into React core concepts and app structure

Both projects are deployed and can be previewed live:

- Hello World: https://hello-world-green-seven-78.vercel.app/
- Core Concepts: https://react-seven-rho-47.vercel.app/

## Overview

This repo is a practical learning path for understanding how React works in real projects. It demonstrates the journey from a minimal app setup to a more structured React application using Vite, JSX, components, and modern frontend tooling.

The aim is to help learners build a solid understanding of:

- React component basics
- JSX syntax and rendering
- Project setup with Vite
- UI composition and reusability
- modern frontend development workflows

## Apps Included

The `hello-world` project is the starting point for learning React with Vite. It introduces the basics of:

The `core-concepts` project expands the foundation by exploring React's core ideas and application structure. It is intended to strengthen understanding of:

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js (v18 or later recommended)
- npm or yarn

### Run a project locally

1. Clone the repository:

```bash
git clone https://github.com/Blexedpritam/React.git
cd React
```

2. Navigate to the project you want to run:

```bash
cd hello-world
# or
cd core-concepts
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL displayed in the terminal in your browser.

## Build for Production

```bash
npm run build
```

This will generate a production-ready build in the `dist` folder.
